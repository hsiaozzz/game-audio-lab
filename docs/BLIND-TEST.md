# 游戏音效偏好盲测

本地临时页面：http://127.0.0.1:4178/blind.html 。本实验由用户自行试听和选择，
代理不代填用户的偏好，不提前给出胜负。

## 赛程

八类相近事件分别有两段声音。当前两个参赛方是纯程序合成和 Kenney 预处理参考；
混合版直接包含参考素材，所以不参加这轮评选。

每个会话分别随机打乱题目顺序、随机安排每题 A/B。答题时隐藏来源、文件名与事件
名称，后端保存映射。全部完成后才返回来源和明细，不在页面脚本里预置答案。

所有片段均从 `sfx-*-matched.wav` 取对应的 1.8 秒区间，用 PCM16 WAV 播放，
不改变响度、不增加有损编码。它们已按同事件做常量增益匹配，源 WAV 最大差 0.10 LU；
保留不同事件各自的动态。匹配过程与声音来源见实验报告，答题前无需阅读来源分析。

## 操作与计分

1. 听 A 和 B，可以回听。两侧均自然播放结束后才能提交；中途切换不会算听完。
2. 选择 A 更好、B 更好、差不多，或都不喜欢。
3. 完成八题后查看总分、胜出次数、平局和每题来源。

胜出得 1 分；平局双方各 0.5 分；都不喜欢双方 0 分。每方最多 8 分。
“都不喜欢”保留为独立结论，避免把两段都不合格误计为同样优秀。

结果属于这位听者对这八组的偏好，适合指导后续改进。是否适合实际游戏，还需要
结合反馈语义、连续触发与 BGM 一起听。尤其科幻场效与升调蓄力虽属相近用途，声音
身份仍可能不同；最终明细保留事件信息，便于区分题材偏好和制作品质。

## 数据与复现

会话 ID 保存在本页 localStorage，刷新可以继续当前会话，刷新后未提交的题需要重新
听两侧。重开创建新随机会话，不覆盖已有结果。

后端会话与映射保存在 `artifacts/blind-sessions/`。静态服务器拒绝直接读取这个目录；
正常 API 在投完八题前不返回映射。当前服务为本地研究服务；重启后可从落盘记录恢复
未完成或已完成的会话。恢复时核对两份音源的 SHA-256；音源改变会拒绝沿用旧会话，
需要重新开始。原始会话含随机映射与投票记录，只保存在本地，不随 Git 仓库分发。

自动化检查使用独立 `purpose: qa` 会话，只验证匿名、播放、投票与计分流程。
它们不作为用户听审结果，也没有汇入跨会话排行榜。

## 已有人工试听

2026-11-16，一位听者完成当前八组样本的盲测：纯合成 4.5 分，Kenney 3.5 分；
纯合成 3 胜、2 负、3 平。这里只保留匿名汇总，不包含会话 ID 或逐题投票。
样本量不足以形成统计性的品质结论，也不代表 BGM 或所有游戏音效。
