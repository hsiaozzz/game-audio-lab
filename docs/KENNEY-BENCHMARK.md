# Kenney 音效质量参照实验

2026-11-16。本文是独立 GameAudioLab 的对照设计与参考素材分析，不是已完成的主观音质
排名。用户自备的原始 `audioX` 目录仅被读取，没有改动；本轮没有浏览或下载素材。

## 已下载素材盘点

目录共 **5 包、408 个 OGG、9,261,667 bytes**，是短音效及循环声素材。它们可以作为
音效制作参照，不能据此验证一首完整 BGM 的作曲或编曲质量。

| impact-sounds | 130 | 1,034,296 | 材质、轻中重冲击、不同地面脚步、编号变体 |

素材包名称和文件名已经体现了值得学习的设计：先区分事件与材质，再组织力度和变体。

包的官方 CC0 来源与本地原始/处理后哈希记录在 `docs/ASSETS.md` 和

许可，并保留了来源说明；没有声称本地文件与新下载的官方 archive 做过逐文件比较。

## 实际可量化的信息

下表分析的是本地 prepared WAV，不是主观打分。总时长包括保留的尾部；峰值时刻从
声音文件开头计算；E50 是累计平方能量达到 50% 的时刻。功率谱重心只统计 ≥20 Hz，
先去均值，再对完整短音效求 FFT。没有在整段瞬态上套一个会压低开头冲击的 Hann 窗。
这种方法适合描述这一组文件，数值不能当成所有 SFX 的通用目标。

| 事件 | 文件时长 ms | 峰值时刻 ms | E50 ms | ≥20 Hz 功率谱重心 Hz | 谱能量/包络提示 |
|---|---:|---:|---:|---:|---|
| ui | 96.1 | 0.1 | 0.2 | 2,155 | 能量极集中在起音；音色不是一段持续鸣叫 |
| collect | 317.5 | 0.2 | 15.7 | 2,568 | 约 99.6% 可听频带功率落在 2–8 kHz，确认感偏明亮 |
| cast | 393.1 | 172.0 | 187.2 | 5,091 | 不是开头最响；中段建立后衰减，主要是高频空气/摩擦区域 |
| footstep | 773.7 | <0.1 | 0.3 | 690 | 总文件时长远长于主要冲击能量，主要功率位于 200 Hz–2 kHz |
| hit | 328.8 | 0.7 | 2.5 | 273 | 起音快速、主体偏低中频；约 53.5% 可听功率低于 200 Hz |
| laser | 235.3 | 1.3 | 47.1 | 724 | 短时事件，能量分布比 click 更持续，主体偏低中频 |
| charge | 871.0 | 136.8 | 157.6 | 218 | 有明显建立过程，约 91% 可听功率低于 200 Hz |
| explosion | 776.5 | 0.5 | 200.0 | 299 | 起音早、主体持续；约 75% 可听功率低于 200 Hz |

文件时长、峰值、能量分布和频带可以帮助确定包络、滤波、共振及分层方向。还应在短时
频谱和包络图中检查频率是否随时间变化、瞬态有几次、尾音如何衰减。只看整段谱重心
不能区分“音高扫频”与“多个不同频带层依次出现”。

这些指标不能证明声音更精美、更逼真或更适合游戏。例如：

- 更宽频、更响、尾音更长，并不必然更好。
- 高频更多可能带来刺耳；低频更多可能浪费手机播放和混音余量。
- explosion 参考约 20% 的非 DC 频谱功率在 20 Hz 以下，说明频带预算值得检查；
  不能以增加次声能量作为“做得更像专业爆炸”的目标。
- 技术上相近的两段声音，仍可能在材质辨识、悦耳度和重复疲劳上差异很大。
- 清晰的文件命名、频谱和包络不能反推出作者使用了哪些真实录音、滤镜或具体设备。

## 当前纯合成方案的具体差距

根据当前 `src/audio-engine.mjs` 的 recipe 做工程分析，尚未据此下听感优劣结论：

| 事件 | 当前纯合成结构 | 下一轮应重点对照的差距 |
|---|---|---|
| ui | 短正弦上扫 | 起音形状、阻尼和重复舒适度；可以精修成优秀 UI，但不应只是压短一个 beep |
| collect | 两个与调性相关的音 | 音乐一致性有优势；需比较起音、亮度和尾音，避免奖励声过长或高频刺耳 |
| cast | 开头衰减噪声＋降调三角波 | 参考的主要能量在中段，当前开头最强；需要有建立、掠过和收尾的包络结构 |
| footstep | 单次低通噪声＋低音下扫 | 缺少地面材质、鞋底接触/摩擦阶段、力度及非连续重复变体 |
| hit | 三角波下扫＋低通噪声 | 缺少不同材质的共振频率、阻尼与瞬态层；不能只调整音高代表材质 |
| laser | 单锯齿大幅下降扫频 | 需比较扫频曲线、谐波控制、共振和瞬态；参考与目标的世界观也必须一致 |
| charge | 两个上升音调 | 目前更像音乐化升调，参考偏低频场效；应先决定目标身份，再设计调制、建立和释放 |
| explosion | 低频下扫＋低通衰减噪声 | 已有主体与噪声两层；还要比较瞬态、碎裂纹理、分段衰减及手机扬声器可辨性 |

当前同类纯合成声音的主结构较固定，变化主要在噪声 seed。进一步提升应制作可审听的
声音 recipe：多阶段包络、几组有身份的共振/调制、带材质约束的变体，仍然保持语义清楚。
第一轮不要为了追求“复杂”而无差别增加混响和噪声。

## 三路试听如何公平解释

根实验已生成完全同事件、同顺序的三路试听：

1. **procedural-only**：仅程序合成。
2. **reference-sample-only**：仅选定 Kenney 参考样本。
3. **hybrid**：参考采样与程序合成按配方组合。

实际处理脚本为 `scripts/compare-sfx.mjs`。每个事件占 1.8 秒，在区间起点后 0.2 秒
触发；每路使用相同事件顺序和触发时刻。脚本分别用 FFmpeg EBU R128 测量每个区间，
为同一事件的三种版本选取共用响度目标，以常量增益匹配，并在需要时降低该事件的共用
目标，保留约 3 dB true-peak 余量。没有加入限制器或动态压缩来改变对照。

经过两遍测量与校正，**WAV 中同一事件三种版本的最大响度差为 0.10 LU**，自动电平
检查通过。不同事件之间的目标并非强制相同：高峰均比的 UI、脚步、木击为了保留峰值
余量，分别降低了共用目标。这是一种明确且可复现的电平控制，不等同于人工证明三者
感知响度完全一致。短音效的 EBU 读数仍需在试听时谨慎解释。

| 事件 | 共用目标 LUFS | 匹配后三路最大差 LU |
|---|---:|---:|
| ui | -32.93 | 0.03 |
| collect | -23.00 | 0.01 |
| cast | -23.00 | 0.04 |
| footstep | -30.55 | 0.10 |
| hit | -24.32 | 0.00 |
| laser | -23.00 | 0.04 |
| charge | -23.00 | 0.03 |
| explosion | -23.00 | 0.06 |

整条 reel 的 integrated LUFS 可以不同，因为 EBU 的 gating 与各事件的不同目标会
影响整段汇总；不能用整条 reel 的不同 LUFS 推翻已经记录的逐事件匹配。原始轨、逐
事件增益、各次测量与成品哈希见 [sfx-comparison.json](../artifacts/sfx-comparison.json)。

试听文件：

- [纯程序合成 MP3](../artifacts/sfx-synth-listen.mp3) / [匹配电平 WAV](../artifacts/sfx-synth-matched.wav)
- [Kenney 参考 MP3](../artifacts/sfx-reference-listen.mp3) / [匹配电平 WAV](../artifacts/sfx-reference-matched.wav)
- [采样＋合成混合 MP3](../artifacts/sfx-hybrid-listen.mp3)；对应 matched WAV 仅在研究机器保留，不随仓库分发。

MP3 供方便试听；0.10 LU 的逐事件匹配结论针对 WAV 测量，不能未经测量扩展为所有
有损编码输出的逐事件精度。

试听建议先盲听一次，再对照标签；分别判断事件辨识度、材质、起音手感、烦躁/刺耳、
连续触发与 BGM 共存。独立声音和实际玩法混音都要评估。本次后续匿名盲听已完成：
一位听者、八类事件，纯合成 4.5 分对 Kenney 3.5 分，3 胜、2 负、3 平。
这个小样本偏好不能推广为整体质量排名，详见 [实验报告](../REPORT.md)。

**hybrid 本身含参考采样，所以它的效果不能证明纯合成已经达到或超过 Kenney。**
当前 footstep 的 hybrid 路径没有叠加额外合成层，实际上是 sample-only，应在结果中
明确标记。若 hybrid 更好，只能支持“这种采样/合成组合对该事件有效”的判断。

## 对独立产品的建议

把 Kenney 这类整理完整、可明确授权的声音库作为可交付质量基础与审听标尺，同时
独立推进可控的程序音效设计。用户提示词决定世界观、材质、反馈语义和风格，系统再
选择合适音源及变体，并进行混音；不需要所有事件都强制从振荡器重新制造。

如需声明“生成的纯合成音效达到此参照水平”，应针对每种事件分别取得匹配响度下的
听审结论，并报告没有达标的类别。BGM 则需要另外的完整音乐参照，检查主题、曲式、
编曲和循环疲劳；这五包 SFX 不能替代那部分验证。
